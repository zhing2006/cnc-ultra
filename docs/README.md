## 宪法

四份宪法规定这个项目做什么，以及按什么原则来做。产品宪法划定范围，另外三份在这个范围里各管一块。几份之间如果出现冲突，先提出来，由项目负责人决定。

### 效力

宪法的效力高于其他文档和任务说明。任务和宪法冲突时，先停下来提出，不要自己选一边做下去。

### 修订

修改宪法要经过项目负责人同意，并且在提交信息里写明改了哪一条、为什么改。每份宪法开头都写着版本和批准日期，修订时按下面的规则升版本号：

- 删除条款，或者把条款改成和原来不兼容的意思，升主版本号。
- 新增条款，或者大幅扩展已有的条款，升次版本号。
- 只改措辞或者修正错误，不改变意思，升修订号。
