# 里程碑 7：地图生成器

状态：完成。2026-10-26，项目负责人确认按本任务单的范围完成 M7。

## 目标

用原版温带瓦片生成 Ultra 模式的大地图。双方从东西两侧交战，中间留出大面积平原，南侧是海滩和连续海域。北部放置成片山崖和疏密不同的树林，支援用地附近保留少量矿区。

地图容量按双方各一万辆地面车辆计算，不依赖步兵共用格子或者飞机不占地面格子来缩小地图。

## 交付范围

- 入口是 `?mode=ultra`。地图生成、后续的单位放置和会战使用同一个入口。
- 默认尺寸为 512×256 格，也可以选择 384×256 和 640×320。URL 中的 `seed` 和 `size` 用于复现地图。
- 支持整图查看、最近邻缩放、拖动和方向键移动。布局辅助线标出部署区、支援用地、沿海交战带和炮艇巡逻线。
- 从运行时读取的原版温带地图中统计瓦片拼接规则。山崖保留原版地图中的完整地形组合和朝向，成组放在北部，不把细小山崖片段随机撒满地图。
- 部署区延伸到海岸内侧，支援用地随己方部署区定位，矿区放在附近。扣除设施、矿区预留地和地形障碍后，每方至少有一万格可部署空间。
- 炮艇巡逻线贯通东西，沿海交战带按现有炮艇射程布置，不修改单位的数值或行为来适应地图。
- 生成结果沿用原版地图的 `Scenario` 数据结构，明确区分存储尺寸和可玩区域。同一种子和尺寸生成相同结果。

## 本阶段不做

2026-10-26，项目负责人确认以下范围：

- Ultra 不生成河流。原版地图和战役的河流素材、解析、渲染和通行规则保留。
- 不在生成地图上放置单位和建筑，不接入普通对战。大地图模拟接入、部队部署和实际交战由里程碑 8 完成，本阶段免除原有的 M6 对战验收要求。
- 不验收采矿路线、经济平衡、空军补给节奏或登陆流程。矿区用于地形点缀，本阶段验证双方各一万辆车的静态部署空间。
- 因为没有所需设备，本阶段免除 NVIDIA、AMD 双 GPU 验收，相关验收留给里程碑 8。当前设备上的渲染检查不能代替双 GPU 验收，也不能证明两万单位实战性能。
- 不生成沙漠和冬季地形，不做地图编辑器。

## 实现位置

- `src/game/map-generator/samples.ts`：原版地图的拼接规则和完整地形组合。
- `src/game/map-generator/layout.ts`：部署区、支援用地、矿区和沿海位置的统一布局。
- `src/game/map-generator/generator.ts`：确定性地图生成。
- `src/UltraApp.svelte`：Ultra 入口和地图查看操作。
- `src/game/formats/scenario.ts`、`src/game/scene.ts`、`src/game/map-visuals.ts`：不同地图尺寸的静态数据和绘制。
- `src/engine/indexed/pipeline.ts`：按视口尺寸生成缩小后的索引图，不分配整张大地图的像素纹理。

## 验收标准

- 生成地图中所有相邻瓦片都符合从原版地图读出的拼接规则。（自动测试）
- 同一种子和尺寸生成两次，地形、对象位置和布局数据相同。（自动测试）
- 山崖组合中的瓦片与原版来源对应，保留完整的连通形状，地形组之间留有空地。（自动测试、画面检查）
- 三种界面尺寸下，扣除设施、矿区预留地和地形障碍后，每方仍有至少一万格可部署空间。支援用地跟随己方部署区，矿区不覆盖支援用地。（自动测试）
- 炮艇预留巡逻线全程在水域内，沿海交战带在现有武器射程内。（几何检查，不运行战斗）
- Ultra 页面能够切换种子和尺寸、缩放和拖动；重新载入 URL 后恢复同一张地图。（浏览器检查）
- 地形整体像原版地图，山崖轮廓清楚、树林有疏有密，平原留有会战空间。（项目负责人查看画面）
