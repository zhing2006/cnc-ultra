# 里程碑 7：地图生成器

## 目标

用原版的温带瓦片，生成 Ultra 模式用的大地图。地图中间是一大片平原，留给两边会战。河流、山崖、树林和矿区放在战场的边上，或者零散地点缀在平原上。地图要像原版设计师画的那样（设计宪法第九条）。

## 原因

原版的地图最大只有 64×64 格（技术宪法第十七条），放不下两万个单位的会战，所以 Ultra 模式要用生成的大地图。地图上不生成山口这类很窄的通道，因为单位按格子占位，几千个单位挤过一个窄口会排成长队。

## 范围

要做：

- 从原版的温带地图里统计出瓦片之间的拼接规则，也就是河岸、山崖、道路和海岸的边缘怎么接。
- 生成平原、河流、山崖、树林和矿区，矿区靠近能建基地的平地。
- 不生成很窄的通道。
- 同一个种子生成同一张地图。
- 生成的地图和原版地图用同一种数据结构，可以直接载入游戏。

不做：

- 沙漠和冬季的地形，`assets/dev/` 里只有温带的 `temperat.mix`。
- 地图编辑器。

## 参考

- `assets/dev/general.mix` 里的温带地图：任务地图的文件名以 scg 开头，多人地图以 scm 开头。
- 原版的 `refs/source/cnc-tiberian-dawn/CDATA.CPP`：地形模板的类型和尺寸。
- OpenRA 的 `refs/source/openra/mods/cnc/tilesets/temperat.yaml`：模板的分类，只用来对照。

## 验收标准

- 生成的地图上，每一对相邻的瓦片都符合拼接规则。（自动测试）
- 用同一个种子生成两次，两张地图逐字节相同。（自动测试）
- 生成的地图可以直接拿来打里程碑 6 的对战。（试玩检查）
- 地图看起来像原版设计师画的：河流有走向，山崖连成片，树林有疏有密。（试玩检查）

## 待定问题

- 地图的尺寸。要放得下两万个单位，还要留出会战的空间，开工时按格子占位的规则来估算。
