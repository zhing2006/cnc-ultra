# 里程碑 1：原版画面

## 目标

把 scg08eb 上剩下的东西也画出来，包括覆盖层、弹坑、树木这类地形物件和建筑，以及它们的阴影。加上隐形坦克的扭曲效果和水面的调色板循环。镜头可以按整数倍放大。

## 原因

里程碑 0 定下了渲染管线，这一步把原版地图上会出现的每一种静态的东西都放进这条管线。从里程碑 2 开始，东西要动起来了，所以画面这部分到这里就要齐全，后面的里程碑只需要往上加动画和界面。

## 范围

要做：

- 覆盖层（泰伯利亚矿和围墙）、地上的弹坑和焦痕、树木这类地形物件、建筑，以及它们的阴影。
- 隐形坦克的扭曲效果。它和阴影一样，要读底下像素的索引。
- 水面的调色板循环。
- 物体互相遮挡时，叠加的顺序和原版一致。
- 镜头可以按整数倍放大，放大时按最近邻采样（设计宪法第二条）。

不做：

- 动画和模拟，建筑和单位都是静止的。
- 镜头缩小到 1 倍以下，放在里程碑 8。
- 侧边栏和雷达，放在里程碑 5。

## 参考

原版源码在 `refs/source/cnc-tiberian-dawn/`：

- `OVERLAY.CPP` 和 `ODATA.CPP`：覆盖层。
- `SMUDGE.CPP` 和 `SDATA.CPP`：弹坑和焦痕。
- `TERRAIN.CPP` 和 `TDATA.CPP`：树木这类地形物件。
- `BUILDING.CPP` 和 `BDATA.CPP`：建筑。
- `TECHNO.CPP` 里画单位的 `CC_Draw_Shape`，带着 `SHAPE_PREDATOR`：隐形坦克的扭曲效果。
- `CONQUER.CPP` 的 `Color_Cycle`，以及 `DEFINES.H` 的 `CYCLE_COLOR_START` 和 `CYCLE_COLOR_COUNT`：水面的调色板循环。
- `LAYER.CPP` 的 `LayerClass::Sort` 和 `LayerClass::Sorted_Add`：物体的叠加顺序。

## 验收标准

- 新增的每一类 SHP，解码结果都和 OpenRA 的 `--png` 导出的图逐像素一致。（自动测试）
- 摆出几组互相遮挡的物体，读回索引图，遮挡关系和原版的叠加规则一致。（自动测试）
- scg08eb 上的所有东西都按地图画了出来。（试玩检查）
- 放大到 2 倍和 3 倍时，像素仍然方方正正，没有模糊。（试玩检查）
- 水面的颜色按原版的节奏循环。（试玩检查）

## 开发约定

- 滚轮逐档切换整数倍，以鼠标指向的地图位置为中心。`+` / `-` 键以画面中心缩放。初始倍率沿用 M0 按画布高度选择的方式，手动缩放范围为 1 倍到 16 倍。
- 游戏地图比窗口窄或矮时，在对应方向居中显示，留白对齐原始图像像素。滚轮约每两格改变一级，触控板的小幅滚动累计后再缩放。
- 默认入口显示 scg08eb。URL 参数 `?preview=assets` 打开素材预览，按分类平铺单位、建筑和地形物件，可以切换阵营、朝向、建筑损伤状态和倍率。47 种单位包括车辆、步兵和飞机的静态图像；65 种建筑分布在温带和沙漠两个场景中。
- 预览区域比窗口窄时水平居中，边缘对齐设备像素。放大后超过窗口宽度时，可以横向滚动查看。
- scg08eb 初始没有隐形坦克。预览页的隐形分类同时展示六种显示状态，以及与树木、建筑重叠的情况。单位分类也可以单独切换隐形坦克的显示状态。

## 开发记录

- 场景已经接入覆盖层、地面痕迹、64 个地形物件和 38 个建筑，包括建筑底下的 bib。物件的排序位置来自各类的 `Sort_Y`，载入顺序来自 `INI.CPP` 的 `Read_Scenario_Ini`。地图载入期间 `ScenarioInit` 允许重叠摆放，所以保留了同在 3660 格的 V02 和 V11。
- `CELL.CPP` 的 `Tiberium_Adjust(true)` 会随机选择矿石的外观。静态场景按固定种子和格子编号选择外观，再按原版的邻居数量确定密度帧。单个格子的随机结果不与原版的一次开局逐格对应。
- 隐形效果的偏移序列和非透明像素计数来自 `KEYFBUFF.ASM`。不同状态如何组合普通图像、`SpecialGhost` 和扭曲，来自 `TECHNO.CPP` 的 `Techno_Draw_Object` 与 `CONQUER.CPP` 的 `CC_Draw_Shape`。预览以每秒 15 个相位步进展示扭曲，不运行隐形状态的模拟。
- 预览中的右半边在全部八个相位都使用负向偏移表，读取下一行左侧的像素。原版方向判断依据是逻辑帧总数 `Frame` 的符号，不能用取模后的相位代替。预览暂不保留开局 `Frame == 0` 的特例；接入模拟时需要传入真实逻辑帧再处理。
- `SpecialGhost` 的淡出目标使用 `WWSTD.H` 中的 12 号色 `BLACK`。建筑初始血量按 `COORDA.ASM` 的 `Fixed_To_Cardinal` 四舍五入，损伤帧选择和武器工厂屋顶的显示使用相同换算。
- GPU 合成按绘制顺序寻找采样位置下方的像素，物件仍在一次 instanced draw call 中绘制。静态空间索引在设置物件列表时建立，鼠标使用单独的末尾实例更新。后续接入移动物件时，需要由 GPU 更新排序和空间索引。
- 已与 Nyerguds 源码交叉核对。其分支修改了简单建筑损伤帧、发电厂的损伤标记和地图弹坑类型的读取；这里保留 EA 源码中的规则，分别见 `BUILDING.CPP`、`BDATA.CPP` 和 `SMUDGE.CPP`。
- 预览读取 `assets/dev/desert.mix`，文件复制自 `refs/cnc-gold/gdi/desert.mix`，SHA-256 为 `0141d371bdb847e085984bca44a0f96cb2f2f410d5eba1410b8e498087954072`。普通任务入口仍只读取原来的四个 MIX 文件。
- OpenRA 参考导出覆盖了 350 个文件。新增的围墙含有全透明帧，`--png` 会省略这些帧，参考摘要按原始头部的尺寸补回全零像素。另有 18 个文件暴露了 PNG 导出的偏移问题：裁剪后的尺寸恰好等于原始尺寸时，导出命令没有应用非零偏移。`refs/export-png.ts` 编译导出命令时修正了这个判断，并恢复源码；OpenRA 的格式解析器没有改动。

## 验证记录

2026-10-24，Windows 上的 Chromium 156.0.8078.4，NVIDIA GeForce RTX 5090 D，驱动 32.0.16.1664。

- `pnpm check`：`svelte-check found 0 errors and 0 warnings`。
- `pnpm test`：4 个测试文件通过，366 个测试通过。包括 OpenRA 参考摘要、地图摆放、覆盖层邻接、建筑损伤帧、水面周期和缩放位置。
- `pnpm test:e2e`：4 项检查通过。新增检查进行了 25 次 GPU 索引图对照，覆盖遮挡、8 个扭曲相位和水平、垂直裁切；另检查了 2 倍、3 倍的像素块、地图和预览区域居中、滚轮灵敏度、居中后的鼠标缩放位置，以及预览页的分类、换色、朝向、损伤状态和场景切换。
- `pnpm build`：通过。
- 开发中修复了隐形采样越过视口后读取画面外物件的问题，以及高血量建筑在选择废墟预览时仍显示损伤帧的问题。对应检查都先复现了失败，再确认修复通过。
- 验收修复先更正了 `tests/reference/paint.ts`，确认第 0 相位在三个视口都发生像素对照失败，再修正 shader。建筑血量的回归检查也先复现了炼油厂错误显示废墟、武器工厂漏画屋顶，再确认修复通过。

已经查看初始地图、Nod 基地和素材预览的浏览器画面。2026-10-24，项目负责人确认验收通过。Ultra 规模的帧率未实测。
