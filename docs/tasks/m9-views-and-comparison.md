# 里程碑 9：透视视图和对比场景

## 目标

完成切片的最后两项，透视视图和 CPU 与 GPU 的对比场景（产品宪法第四条第三点和第四点）。做完以后，切片按产品宪法第七条整体验收。

## 原因

玩家看不出模拟跑在 CPU 上还是 GPU 上（产品宪法第三条）。透视视图让人亲眼看到上万个单位是怎么找到路的，对比场景让人直接读出 GPU 带来的帧率差距。

## 范围

要做：

- 透视视图。流场、视野和矿区密度这三层已经在里程碑 2、3 和 5 里做好了，这一步统一它们的开关和配色。配色要和原版的调色板明显不同（设计宪法第八条），开关放在原版界面之外（设计宪法第七条）。
- 对比场景。同一个场景，一边跑 CPU 版的模拟，一边跑 GPU 版，单位数量相同，两边并排显示帧率。CPU 版在 Worker 里运行，不能卡住主线程。界面上写明 CPU 版用了几个线程。

不做：

- 给 CPU 版另写一套更快的算法。对比场景里的 CPU 版就是技术宪法第十五条规定的那个 CPU 版，两边做的是同一份工作。

## 参考

- 技术宪法第十五条：CPU 版和 GPU 版逐位一致。
- 设计宪法第七条和第八条：新增界面和透视视图。

## 验收标准

- 对比场景里，两边在同一个逻辑帧上的模拟状态相同。（自动测试）
- 透视视图的每一层都能单独开关，打开以后照样能选择单位、下达命令，单位和地形没有被遮得看不清。（试玩检查）
- 对比场景里两边的单位数量相同，帧率并排显示，差距可以直接读出来。（试玩检查）
- 产品宪法第七条的四点逐条检查通过。（试玩检查）

## 待定问题

- CPU 版用几个线程。
- 对比用什么场景、放多少个单位。
