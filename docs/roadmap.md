# 路线图

路线图把产品宪法第四条规定的第一版拆成十一个里程碑，也就是里程碑 0 到里程碑 9，再加上排在里程碑 6 后面的里程碑 6.5，按顺序完成。每个里程碑做完都要能在浏览器里看到结果（技术宪法第十二条），按任务单里的验收标准检查通过以后，再开始下一个。每个里程碑做什么、参考哪些原版代码、怎么验收，写在 `docs/tasks/` 里对应的任务单中。

## 为什么按这个顺序

里程碑 0 从原版的 MIX 文件一直打通到屏幕，格式解析、GPU 纹理和 TSL shader 都要走一遍。阵营换色和单位的阴影也在这一步做，因为阴影要读底下像素的索引，它决定了整条渲染管线的样子。后面的任务都照着这一步的代码来写，引擎层和游戏层怎么分，TSL 怎么写，测试怎么写，都以它为样板。

GPU 模拟是这个项目里最没有把握的部分。用 TSL 写整数定点数的 compute kernel 顺不顺手，几个单位同时抢一个格子时怎么保证结果确定，读回的延迟会影响哪些逻辑，这些都还没有验证过。所以原版的画面一画出来，里程碑 2 就搭模拟框架，之后的游戏规则都建在这个框架上。如果这条路走不通，越早发现越好。

开始做 Ultra 模式之前，先要有一个完整的原版游戏。里程碑 6 证明原版地图上的一局对战能从开局打到分出胜负，里程碑 6.5 再补上开场动画、主菜单和两边的全部战役。

Ultra 模式和原版地图用的是同一套规则（设计宪法第五条），所以先在原版地图上把规则做完整，再放大规模。有些问题只有规模变大才会出现，比如几千个单位怎么选择、镜头拉远以后怎么画、上万次开火的声音怎么处理，这些留到 Ultra 的里程碑里解决。两万个单位能不能保持每秒 60 帧，也在那个里程碑里验收。

## 贯穿各个里程碑的做法

- 每个在 GPU 上运行的模拟系统，都和它的 CPU 版一起写，两边逐位一致（技术宪法第十五条）。模拟里的随机数按第十六条来算，地图尺寸按第十七条不写死。
- 流场、视野和矿区密度这三层透视视图，分别跟着对应的系统一起做，在里程碑 2、3 和 5 里。开发的时候它们也是调试工具，比如单位走错了路，打开流场的透视层看一眼方向，就知道问题出在哪里。
- SHP 和地形模板的解码，对照 OpenRA 导出的图。画面怎么叠加按原版源码来写，叠出来的效果在试玩时检查，整幅画面不和原版游戏的截图做对照。

## 里程碑

### 里程碑 0：调色板管线

把 GDI 任务地图 scg08eb 的地形、车辆和步兵画出来，单位带阵营颜色和阴影，定下调色板索引渲染的管线（技术宪法第三条）。镜头照原版的方式滚动。

出关标准：scg08eb 的地形和单位按地图画了出来，两方的阵营颜色分得清，单位的阴影压暗了底下的地面。镜头能滚到地图的每个角落。

### 里程碑 1：原版画面

把 scg08eb 上的矿、围墙、树木和建筑也画出来，加上隐形坦克的扭曲效果和水面的调色板循环，镜头可以按整数倍放大。

出关标准：整张 scg08eb 按地图画了出来，放大以后像素不模糊。

### 里程碑 2：GPU 模拟框架

搭好模拟的骨架，包括定点数、逻辑帧、状态校验和、随机数、格子占位和流场寻路，每个系统都同时写 CPU 版和 GPU 版。

出关标准：几百个单位在 scg08eb 上顺着流场走向目标，一格只停一辆车。执行同一串命令，CPU 版和 GPU 版的校验和相同。

### 里程碑 3：单位和操作

车辆和步兵按原版的数值移动，玩家可以像在原版里一样选择单位、下达命令。视野、迷雾和单位的语音也在这一步做。

出关标准：选择和下命令的方式和原版一致，单位走一段直路用的逻辑帧数，和按原版数值算出来的相同。

### 里程碑 4：战斗

地面单位之间按原版的规则交战，包括武器、弹头、子弹、爆炸和音效。

出关标准：伤害和摧毁一个单位用的时间都和原版的公式一致。很多颗子弹同时打中同一个单位时，CPU 版和 GPU 版仍然逐位相同。

### 里程碑 5：经济和建造

从一辆 MCV 开始造基地、采矿、生产单位，加上原版的侧边栏、雷达和 EVA 的语音提示。

出关标准：从 MCV 开局能一路造到出兵，价格和建造时间都和原版一致。

### 里程碑 6：原版地图上的一局对战

在原版的多人地图 scm01ea 上，玩家和电脑对手各从一辆 MCV 开局。电脑对手从重制版的 AI 移植（设计宪法第一条），多人模式的科技树补齐，包括飞机和两种超级武器。

出关标准：一局从开局一直打到一方被消灭，中途不刷新页面（产品宪法第七条第一点）。

### 里程碑 6.5：原版战役

从原版的开场动画和主菜单进入游戏，GDI 和 Nod 两边的战役都能从第一关打到结局。过场影片、任务简报、选关地图、计分画面、音乐、游戏内的选项菜单和存档都照原版来做，沙漠和冬季的地形也在这一步补上。主菜单里联机的入口保留，但是不能使用（产品宪法第五条）。

出关标准：两边的战役都从第一关打到结局，每一关都能取胜（产品宪法第七条第二点）。

### 里程碑 7：地图生成器

用原版的温带瓦片，生成 Ultra 模式用的大平原会战地图（设计宪法第九条）。

出关标准：生成的地图上，瓦片的边缘都接得上，地图可以直接拿来打里程碑 6 的对战。

### 里程碑 8：Ultra 模式

两个 AI 指挥官各带几千个单位，在生成的大地图上会战。远景的画法、音效的合并和大规模的选择编队都在这一步做。

出关标准：两万个单位同时作战，开发机上保持每秒 60 帧（产品宪法第七条第三点）。

### 里程碑 9：透视视图和对比场景

统一三层透视视图的开关和配色，做出 CPU 版和 GPU 版并排运行的对比场景。

出关标准：满足产品宪法第七条的第四点和第五点。

里程碑 9 完成以后，第一版按产品宪法第七条整体验收。
