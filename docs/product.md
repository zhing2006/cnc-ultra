# 产品宪法

版本 0.1.2，批准于 2026-10-25。

## 第一条 产品

C&C Ultra 在浏览器里重做 1995 年的初代《命令与征服》，画面和声音用的都是原版素材。游戏的模拟跑在 GPU 的 compute shader 上，所以战场的规模可以远远超过原版。原版里二三十辆坦克同时出现在屏幕上就算大场面了，这里要让上万个单位在同一张地图上作战。

## 第二条 玩家

产品主要给两类人看。一类是玩过原版的玩家，他们一眼就能认出原版的画面、声音和手感，哪里做得不对，也是他们最先发现。另一类是对浏览器里的 GPU 计算感兴趣的开发者，他们想知道上万个单位是怎么动起来的。

## 第三条 规模要看得见

玩家看不出模拟跑在 CPU 上还是 GPU 上，所以 GPU 带来的性能必须换成屏幕上看得见的东西，也就是用原版的像素素材打一场上万个单位的仗。技术方案需要取舍的时候，优先选能让规模变大、或者能让人看懂规模从哪里来的那一个。

## 第四条 范围

当前阶段做第一版，包括五个部分：

1. 原版地图上的一局完整对战。游戏读取原版地图，建造、采矿和作战这一圈要能从开局一直玩到分出胜负。
2. 原版的单人战役。游戏从原版的开场动画和主菜单进入，GDI 和 Nod 两边的战役都能从第一关一直打到结局。过场影片、任务简报、选关地图、计分画面、音乐和存档都照原版来做。
3. Ultra 模式。地图生成器用原版的地形瓦片拼出一张大地图，上面有河流、山崖、树林和矿区。双方各有一个 AI 指挥官，各带几千个单位开战。玩家可以旁观，也可以下场指挥其中一方。
4. 叠加层。玩家可以在游戏画面上一键叠加流场、视野、矿区密度和威胁图，亲眼看到上万个单位是怎么找到路的，也能看到电脑对手是根据什么判断局势的。
5. 补全的电脑对手。原版地图上的电脑对手从重制版移植，Westwood 在它的决策框架里留下了几种没有写完的策略。补全以后，电脑对手会根据局势决定进攻、防守还是发展，会发展科技，有了超级武器也会使用。

## 第五条 不做的事

当前阶段不做联机对战，主菜单里联机的入口保留，但是不能使用。原版以外的内容也不做，比如《红色警戒》和资料片《隐秘行动》。联机虽然不做，但是模拟仍然要保持确定性（见技术宪法第六条），这样回放和以后的联机才有基础。

## 第六条 原版素材

开发只使用 EA 在 2007 年作为免费软件发布的 C&C Gold。原版的美术、音效和视频归 EA 所有，不在 GPL 的范围内。仓库里只放开发和测试要用的少量原版文件，其余的素材由使用者自己下载，下载方法见 [refs/README.md](../refs/README.md)。产品对外发布之前，必须换掉全部原版素材，也要换掉带有 EA 商标的名字。

## 第七条 完成标准

第一版满足下面几点才算完成：

1. 在原版地图上，一局对战可以从开局玩到分出胜负，中途不需要刷新页面。
2. GDI 和 Nod 两边的单人战役，都能从开场动画开始，一直打到结局。
3. Ultra 模式在开发机上同时运行两万个单位，保持每秒 60 帧。开发机的显卡是 NVIDIA GeForce RTX 5090 D，CPU 是 AMD Ryzen 9 9950X，浏览器用最新版的 Chrome 或 Edge。
4. 叠加层的每一层都可以单独开关，打开以后游戏仍然能正常操作。
5. 在原版地图上，补全的电脑对手会发展到高级建筑，有了超级武器会使用，和照原样移植的电脑对手对打时，大部分对局都能获胜。
