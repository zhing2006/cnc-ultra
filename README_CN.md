# C&C Ultra

[English](README.md) | 中文

C&C Ultra 在浏览器里重做 1995 年的初代《命令与征服》，画面和声音用的都是原版素材。游戏的模拟跑在 WebGPU 的 compute shader 上，所以战场的规模可以远远超过原版引擎。原版的一张地图上通常只有几十个单位，这里要让上万个单位同时作战。

默认页面会读取原版的 MIX 文件，显示 GDI 第 8 关的地图 scg08eb：地形、泰伯利亚矿、围墙、地面痕迹、树木、建筑、车辆和步兵，带阵营颜色和阴影。水面使用原版的调色板循环。把鼠标推到屏幕边上，或者按方向键，可以滚动地图，也可以按整数倍缩放。单位和建筑保持静止，还不能选择。

## 运行要求

- 支持 WebGPU 的浏览器，比如新版的 Chrome 或 Edge。
- Node.js 24 或更新的版本，以及 pnpm。

## 开始

```sh
pnpm install
pnpm dev
```

然后打开 http://127.0.0.1:5173，点一下画面，鼠标就交给游戏控制，按 Esc 交还。

滚轮以鼠标指向的位置为中心缩放，`+` / `-` 键以画面中心缩放。初始倍率按窗口高度选择，手动缩放范围是 1 倍到 16 倍。

按 `Alt+Enter` 切换全屏。原版的战场操作没有使用这个快捷键。由页面进入全屏后，会为原版的编队和视角书签快捷键启用 Keyboard Lock，让浏览器把 `Ctrl+1` 等组合交给游戏处理。浏览器自己的全屏命令（`F11`）不能启用 Keyboard Lock。Esc 仍然可以释放鼠标、退出全屏。

## 调试入口

打开 http://127.0.0.1:5173/?preview=assets 可以进入素材预览页。单位、建筑和地形物件按分类平铺，可以切换阵营颜色、朝向、建筑损伤状态和整数倍率。温带和沙漠各有专属素材，需要切换场景查看。隐形分类同时展示六种显示状态，并摆放了相互重叠的树木和建筑。

打开 http://127.0.0.1:5173/?demo=simulation 可以进入 GPU 模拟测试场景。scg08eb 上放置了 320 辆可移动坦克，以及五辆展示不同隐形状态的静止坦克。锁定鼠标后，点击可通行的地面，所有可移动坦克都会向目标移动。按 Esc 释放鼠标后，可以在面板上开关流场、暂停、恢复或重置场景。页面切到后台时，模拟会暂停。这个 M2 场景保留坦克的初始朝向，转向和动画在下面的单位操作场景中查看。

打开 http://127.0.0.1:5173/?demo=units 可以进入单位操作测试场景，scg08eb 上放置了 28 辆车和 35 名步兵。锁定鼠标后，左键点选或拖框选择单位，再左键点击地面下达移动命令。Shift 点选可以添加或取消单个单位，右键清空选择。`Ctrl+1` 至 `Ctrl+9` 保存编队，数字键选择编队，`Shift+数字` 追加选择，`Alt+数字` 选择编队并将镜头移到它们所在的位置。用 `Alt+Enter` 进入全屏以接收这些快捷键。`N` 选择下一个单位并移动镜头，`Shift+N` 选择上一个，`Home` 将镜头移到当前选择，`H` 选择 MCV，`S` 停止，`X` 散开。面板可以开关所选部队的流场和当前视野透视层，也可以暂停或重置场景。探索过的地形保持可见，选择和下令时播放原版单位语音。

## 部署

`pnpm build` 会在 `dist/` 里生成一个静态网站，不需要后端，放在任何路径下都能运行。网站要通过 HTTPS 或 localhost 访问，服务器还要返回下面两个响应头，因为页面需要跨源隔离：

```
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

构建产物里不包含原版游戏数据。部署时在 `index.html` 旁边建一个 `data/` 目录，把 C&C Gold 的 `conquer.mix`、`temperat.mix`、`general.mix` 和 `cclocal.mix` 放进去，素材预览页还需要 `desert.mix`，单位操作测试场景还需要 `sounds.mix`。开发服务器把 `assets/dev/` 映射到 `data/`。这些数据归 Electronic Arts 所有，所以这样的站点只能放在内部网络里。

## 游戏数据和参考资料

仓库里没有原版的美术、音效和视频，只有 `assets/dev/` 里开发和测试要用的几个 MIX 文件。在 Windows 上运行 `refs/fetch.ps1`，在其他系统上运行 `refs/fetch.sh`，就会把 2007 年发布的 C&C Gold 免费版和参考源码下载到 `refs/`，详见 [refs/README.md](refs/README.md)。
